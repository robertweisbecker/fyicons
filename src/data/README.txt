# FYIcons

SVG icons from https://icons.bob.fyi/.

This archive contains the icons you downloaded in one `icons/` folder. `manifest.json` lists the included icons with their original names, Figma component IDs, source links, 16×16 canvas dimensions, and SHA-256 checksums.

Every colliding name retains a stable `--node-id` suffix. No variants are merged. The SVGs preserve their source artwork, fills, stroke weights, and opacity. The sun uses the supplied replacement SVG; construction guides have been removed from dir-down. Those changes are recorded in the manifest.

On the website, click an icon to inspect, copy, or download it. Use the checkboxes to select icons, then choose Export selected to download just that set. Selections are saved in your browser. The preview size slider changes only the gallery display; exported SVGs remain 16×16.

The Examples page shows the icons at their native 16px size in interactive React interfaces. Messages, playback, and saves are simulated.
