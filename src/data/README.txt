# FYIcons

SVG icons from https://icons.bob.fyi/.

This archive contains the downloaded SVGs in one icons/ folder. The root manifest.json lists their names, categories, original Figma component IDs, source links, 16×16 canvas dimensions, and SHA-256 checksums.

Variants have distinct numbered filenames instead of Figma node IDs. No variants are merged. SVG files preserve the current editable source artwork, including fills, strokes, opacity, and deliberate optical adjustments. The manifest retains provenance and previous-name aliases.

On the website, click an icon to inspect, copy, or download it. Select icons using their checkboxes and choose Export selected to download a subset. Preview sizing does not change the source SVGs.
