# About

Some icons for you, from [bob.fyi](https://bob.fyi).

`fyicons` is a collection of SVG icons and corresponding React components exported and generated directly from Figma. Each icon is drawn on a 16×16-pixel canvas with a base 1px stroke and a goal of pixel-perfection.

## <IconBeaker className="inline-block size-5 mt-[-0.115em] text-lime-500" /> Pick your poison

For React projects, you can import icon components via `npm install fyicons` or snag local copies with the shadcn/ui registry. For other uses, you can copy or download SVGs individually or in bulk. All formats use the same artwork.

[Get started](/docs/getting-started/) with the format that fits your project, or [browse the icons](/icons/) to explore the collection.

## Updates and contributions

This library is in initial development and is actively changing. Icon names and React exports can change before version 1.0, so review the [changelog](/docs/changelog/) before updating.

Some icon names have naming conventions or numeric suffixes that may change as the library grows, and syntax is locked down. A manifest keeps previous names as lookup aliases for the website; those aliases do not preserve old React export names.

Visit the [GitHub repository](https://github.com/robertweisbecker/fyicons) for source files and contribution instructions. Use its [issues](https://github.com/robertweisbecker/fyicons/issues) to report a problem or request an icon.
