# Colophon

---

FYIcons is designed and maintained by [Robert Weisbecker](https://bob.fyi). Icons are drawn by hand in Figma on a 16×16 grid and are available as SVGs and React components. Read more about the collection and its production on the [About page](/docs/).

This site is built with [Next.js](https://nextjs.org/) and [React](https://react.dev/). It uses [Allo](https://joshpuckett.me/) for interface text and [Paper Mono](https://github.com/paper-design/paper-mono) for code. Both fonts are available under the SIL Open Font License; their notices are available for [Allo](/licenses/Allo-OFL.txt) and [Paper Mono](/licenses/PaperMono-OFL.txt).

The source is available on [GitHub](https://github.com/robertweisbecker/fyicons).
