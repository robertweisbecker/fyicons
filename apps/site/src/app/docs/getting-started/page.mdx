# Getting started

Add icons to your project with SVG or React components.

## React

### npm

Install the package in a project with React 18.2+ or React 19:

```sh
npm install fyicons
```

Import an icon by name and use it as a component:

```tsx
import { IconSun } from 'fyicons';

export function LightButton() {
  return (
    <button type="button" aria-label="Switch to light mode">
      <IconSun />
    </button>
  );
}
```

Icons render at 16 px and inherit the surrounding text color. The [React guide](/docs/react/) covers props, imports, and accessibility.

<h3 id="editable-source-with-shadcn">Editable source with shadcn</h3>

Use the shadcn registry to copy selected icons and their helpers into your project. You can edit the source, and the `fyicons` npm package is not required.

Start with a React and TypeScript project that has a shadcn `components.json` file. If you have not set up shadcn, follow its [installation guide](https://ui.shadcn.com/docs/installation). FYIcons uses a [GitHub registry](https://ui.shadcn.com/docs/registry/github), so you do not need to add a registry namespace to `components.json`.

#### Add icons

[Find an icon](/icons/), open its details, and copy its shadcn command. For example, add the Sun icon from your project directory:

```sh
npx shadcn@latest add robertweisbecker/fyicons/sun
```

To add multiple icons at once, include each icon address in the same command:

```sh
npx shadcn@latest add \
  robertweisbecker/fyicons/sun \
  robertweisbecker/fyicons/moon \
  robertweisbecker/fyicons/heart
```

You can also replace `npx` with `pnpm dlx`, `yarn dlx`, or `bunx`.

#### Use the components

Icons go into a `fyicons` folder under your configured components directory. With the components alias set to `@/components`, import each icon as a default export:

```tsx
import IconSun from '@/components/fyicons/IconSun';

<IconSun size={24} />;
```

Each install includes the shared `base.tsx` and `types.ts` helpers and the MIT `LICENSE`. Keep these files with your icons. The components accept the same [React props](/docs/react/#props), including `size` and `color`.

#### Find icons from the terminal

Search the registry by name without leaving your project:

```sh
npx shadcn@latest search robertweisbecker/fyicons --query heart
```

#### Pin a version

Version pinning is optional. Without a tag, commands use the repository's default branch. Append a release tag to install a specific release:

```sh
npx shadcn@latest add 'robertweisbecker/fyicons/sun#fyicons@0.2.1'
```

For a multiple-icon install, append the tag to each icon address. See the [changelog](/docs/changelog/) for release numbers.

#### Preview updates

Copied components do not update automatically. To preview an update, run the add command again with `--dry-run`. This shows the proposed changes without writing files:

```sh
npx shadcn@latest add robertweisbecker/fyicons/sun --dry-run
```

Use `--diff` instead to inspect file differences. Review changes to your icons and shared helpers, especially if you have edited them locally. Run the command without the preview flag when you are ready to apply the update; the CLI asks before replacing existing files. The [shadcn CLI guide](https://ui.shadcn.com/docs/cli#add) covers all options.

## SVG files

Use SVGs in plain HTML, other frameworks, or design tools. [Browse the icons](/icons/), select an icon, and use **Copy SVG** to copy its markup or **Download** to save its SVG file.

For quick actions, right-click an icon in the grid, or long-press it on mobile. The context menu shows the icon's name and offers **Copy name**, **Copy SVG**, and **Download**.

Download the complete collection as a ZIP:

<DownloadIconsButton />

For a smaller collection, open the [icons page](/icons/) on a desktop screen, select icon checkboxes, open **Saved**, and choose **Download all**. You can also download an individual icon with the download button in its saved row.

Each ZIP contains SVG files, a README, the MIT license, and a manifest with names, categories, and checksums. The preview size control does not change the downloaded files; they keep their 16×16 canvas.

Use the SVG in your markup as you would any other SVG. Keep the default classes to allow [global styling](/docs/styling/#default-classes):
