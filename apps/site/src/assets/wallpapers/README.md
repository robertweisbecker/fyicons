# Demo backdrops

The desktop showcase uses a continuous wallpaper of radial OKLCH gradients in `src/home/desktop/DesktopShowcase.css`. Its pale light-theme colors and deep dark-theme colors run left to right in dock order. Selecting a tab centers its band, with the previous app’s color at the left edge and the next app’s color at the right. The app contents slide inside a shared opaque frame. The traffic lights follow its left edge as the window resizes. Keyboard navigation and reduced motion switch the scene immediately.
