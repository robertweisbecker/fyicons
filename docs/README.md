## Historical records

Files named `icon-sync-YYYY-MM-DD.md` record icon changes at the stated date. Some dates have follow-up records. They record source identities, renames, additions, removals, and verification results. Their counts and behavior can differ from the current source.

- [Release preparation, October 22, 2026](release-preparation-2026-10-22.md)
- [Dependency audit, October 22, 2026](dependency-audit-2026-10-22.md)
- [SVG optimization assessment](svg-optimization-assessment.md): measurements from September 2026; no artwork change is approved by this report.
- [Plans](../plans/README.md): a record of completed work and two open proposals.

Use historical records only when a task needs that history. They do not define the current workflow. Keep private session notes and machine-specific evidence outside the repository.
