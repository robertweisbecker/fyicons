## Foreground color

The user requested `currentColor` throughout the library. Each source SVG now uses `currentColor` for opaque foreground fill and stroke paint. This applies to downloads and clipboard SVGs, as well as React components. This is an explicit paint-only departure from byte-exact raw Figma exports.

Raw exports were retained separately during the sync. A comparison of all 1,053 staged sources confirms unchanged geometry, canvas, non-paint attributes, and protected definition paint. Mask and clip-path colors remain intact. Opacity and transparent paint are preserved.

The React normalizer now recognizes opaque solid colors instead of a fixed list of near-black values. It handles exported colors and Display P3 declarations without changing mask or clip-path paint. Tests cover the palette, geometry, opacity, protected definitions, and color inheritance in every downloadable source. Generated React components, both catalogs, and the category schema were regenerated from source.
