# Figma icon sync — October 8, 2026

Source: [Icons section in icons-astra](https://www.figma.com/design/KA61XWs3LqkOU2bzzvjEeW/icons-astra?node-id=646-192), on the `good` page (`82:2415`).

The initial import contained all 894 component nodes in that section. Every component is 16 × 16. Component-set variants are separate records; sketches, frames, instances, and components elsewhere in the document were outside this import. The subsequent Updated section sync below brings the inventory to 914 icons.

SVGs were exported with `exportAsync({ format: 'SVG_STRING', svgSimplifyStroke: false })`. Source bytes are preserved exactly, including fills and construction geometry present in Figma. No artwork optimization or reconstruction is applied. SHA-256 checks connect each imported SVG to the generated catalogs and downloads. Generated React components use the existing color and instance-ID handling.

Compared with the working source manifest (768 icons, despite the older README count):

- 129 added components.
- 3 removed components.
- 55 canonical names updated, matched by stable Figma component ID.
- 165 retained components have updated SVG bytes.
- 16 category headings now follow the Figma section order.

Source names are normalized to kebab case for SVGs and Pascal case for React exports. Filled variants use `-fill`; the two existing `Property 1` variant sets use their boolean values the same way. Previous names remain lookup aliases where they do not conflict with a current canonical name. Application call sites use the current names while preserving the component identities they referenced before the sync.
